## Flujo entre ChatGPT y Codex
Este repositorio es la fuente central de información compartida. Las conversaciones no comparten necesariamente el mismo historial o memoria, por lo que los acuerdos importantes deben registrarse aquí.

1. Al iniciar una sesión, consulta las instrucciones y documentos principales.
2. Antes de editar, sincroniza la copia local con GitHub y revisa si hay cambios pendientes.
3. Registra los acuerdos duraderos, separando decisiones confirmadas de hipótesis y pendientes.
4. Revisa los cambios y súbelos mediante commits claros.
5. Si se trabaja desde otro entorno, vuelve a sincronizar antes de editar.
