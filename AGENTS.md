# Instrucciones del proyecto: Joyeria

## Fuente de verdad
- Este repositorio es la fuente compartida de verdad para el proyecto de joyería.
- Antes de proponer decisiones como si fueran definitivas, consulta la documentación vigente del repositorio.
- No supongas que el historial de conversación está sincronizado entre ChatGPT y Codex.
- Al iniciar una tarea nueva o sesión, revisa este archivo, `README.md`, `marca-joyas.md` y, si existe, `docs/estado-proyecto.md`.

## Forma de trabajar
- Distingue hechos confirmados, hipótesis, recomendaciones y asuntos pendientes.
- No inventes decisiones, presupuestos, acuerdos con proveedores ni datos de mercado.
- Conserva las decisiones existentes. Si una instrucción nueva contradice una decisión documentada, señala la diferencia antes de reemplazarla.
- Haz cambios acotados y evita sobrescribir trabajo ajeno.
- Antes de editar, comprueba la versión actual de los archivos y los cambios existentes.
- Resume los archivos modificados y las decisiones relevantes al finalizar.
- Documenta los acuerdos duraderos en Markdown dentro del repositorio, no solo en el chat.
- No guardes credenciales, contraseñas, tokens ni datos personales sensibles en el repositorio.

## Sincronización Git
- Antes de trabajar en una copia local, revisa el estado de Git y sincroniza con la rama remota según corresponda.
- No descartes cambios locales sin autorización.
- Antes de subir cambios, revisa el diff y confirma que no incluya secretos ni archivos no deseados.
- Si hay cambios concurrentes o conflictos, resuélvelos explícitamente; no sobrescribas silenciosamente.

## Contexto del negocio
- El proyecto busca desarrollar una marca propia de joyería artesanal en Chile.
- El concepto inicial contempla plata y bronce; existe interés adicional en explorar oro.
- Se busca un taller fabricante que produzca a pedido para la marca, idealmente sin vender diseños propios que compitan directamente.
- CLAF Goldsmith está en evaluación, no debe describirse como proveedor confirmado.
- Consulta `marca-joyas.md` para el contexto disponible y los asuntos aún por definir.
